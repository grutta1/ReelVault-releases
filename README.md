# ReelVault — app downloads

ReelVault keeps the videos and links you want to come back to, and lets friends send each other finds. Android only for now.

**Install page (easiest):** https://api-production-6a85.up.railway.app/get

**Direct download of the latest version:** https://github.com/grutta1/ReelVault-releases/releases/latest/download/ReelVault.apk

How to install
1. Tap the download link on your Android phone. If Chrome asks whether to keep the file, choose **Download anyway**.
2. Open the downloaded file from the notification or the Files app.
3. The first time, Android asks to allow installs from this source. Turn it on, come back, tap **Install**.
4. If a Play Protect box appears, tap **More details**, then **Install anyway**. ReelVault is not on Google Play yet; that is all the message means.

Updates: install the new file over the old one. Your vault stays.

This repository holds only the app files. The source code is private.
